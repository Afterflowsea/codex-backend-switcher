# v1.0.0

> Windows 上一键切换 Codex 后端：ChatGPT 官方账号 ⇄ 多个第三方 API 中转站。

---

## 它能做什么

Codex 只有一个凭据槽位（`auth.json`），账号登录和中转 key 登录互斥。换后端要同时改
`config.toml`、换 `auth.json`、重启 App，手改容易改坏，还经常出现「配置指向 A、key 是 B」的 401。

这个工具把整套流程做成一次操作：

1. **先校验**：请求 `{base_url}/models`，再真实发一次 `/responses`，确认 key 与模型都可用
2. **再关闭 Codex**（它会回写配置，必须先关）
3. **成套替换** `config.toml` + `auth.json` + 代理环境变量
4. **恢复登录态**：账号模式直接还原备份的 tokens，免重新登录
5. **重新打开 Codex**

任何一步校验失败，**一个字节都不会写**，当前配置保持原样。

---

## 主要特性

- 多后端切换，站点数量不限，菜单自动生成
- 切换前校验 key、连通性、模型可用性；失败时打印厂商原始报错
- 账号凭据备份与还原，切回账号无需重新扫码
- 按站点记忆模型（你在界面里换过的模型会被记住）
- 按站点设置代理（只影响需要翻墙的站点）
- 支持附加根级配置项，如 `web_search`、`model_context_window`
- 安装 / 卸载脚本 + 自定义图标
- 离线冒烟测试（33 项，不联网、不碰真实配置）

## 安装

下载本页下方的 `codex-backend-switcher-v1.0.0.zip`，解压后：

```powershell
powershell -ExecutionPolicy Bypass -File .\codex-backend-switcher\bin\install.ps1
```

安装会：

- 把程序复制到 `%LOCALAPPDATA%\CodexSwitcher`
- 在 `%USERPROFILE%\.codex\.switch` 初始化状态目录
- 在桌面创建「Codex 切换」快捷方式

然后把 `providers.json` 里的 `base_url` / `model` / `proxy` 改成你自己的即可。

## 已知限制

- 仅 Windows
- 切换会重启 Codex，当前会话中断
- 账号首次登录仍需人工在浏览器授权（OAuth 安全约束，无法全自动）
- 需要本机已安装 Codex 桌面端
